# 🌟 PokéDrag Race Simulator 🌟

A RuPaul's Drag Race simulator featuring 20 female Pokémon competing for the crown! Built with vanilla JavaScript and featuring a clean, MotherDuck-inspired UI.

## ✨ Features

### Core Functionality
- **20 Female Pokémon Cast** with unique stats, personalities, and entrance quotes
- **Complete Simulator Flow**:
  - Queen Entrances with signature quotes
  - Promo Chart
  - Challenge Selection (Acting, Comedy, Dance, Design, Runway, Makeover, Rusical, and more)
  - Challenge Announcements
  - Performance Descriptions
  - Results Announcements
  - Lip Sync Battles
  - Elimination Ceremonies
  - Grand Finale with Top 4
  - Winner Crowning

### Pokémon Stats System
Each Pokémon has 10 stats rated 1-10:
- Acting
- Improv
- Comedy
- Dance
- Design
- Runway
- Lipsync
- Makeover
- Rusical
- Rumix

### Placement System
- **Regular Episodes** (6+ queens): 1 WIN, 2 HIGH, 1 LOW, 2 BTM2, rest SAFE
- **Top 5**: 1 WIN, 2 HIGH, 2 BTM2
- **Finale**: Triggers when 4 queens remain

### 🎬 Producer's Room
Override placements for any episode to control the narrative:
- Manually select WIN, HIGH, LOW, and BTM2 placements
- Create your own storylines and outcomes
- Full control over competition flow

### 📊 Track Record Table
- Displays all queens sorted by performance
- Current competitors at top, sorted by WIN/HIGH count
- Eliminated queens at bottom in reverse elimination order
- Episode-by-episode placement tracking
- Color-coded badges for easy reading

### 🎭 Drama & Storylines
- Dynamic drama generation between queens
- Personality-based storylines (Perfectionist, Comedy Queen, Fashion Icon, etc.)
- Season-long narrative tracking
- "Tea" moments throughout the competition

### 📈 Season Statistics
Real-time tracking of:
- Episodes completed
- Queens remaining
- Eliminated queens
- Drama moments count
- Recent tea/gossip

## 🎨 Design

Built with a clean, modern aesthetic inspired by MotherDuck:
- Responsive layout (mobile, tablet, desktop)
- Smooth animations and transitions
- Color-coded placements (WIN = Gold, HIGH = Green, SAFE = Gray, LOW = Orange, BTM2 = Red)
- Space Mono monospace font
- Clean card-based layouts
- Gradient accents in signature pink tones

## 🎮 How to Play

1. **Cast Selection**: Choose 10-14 Pokémon from the available 20
2. **Watch Entrances**: See your queens enter the workroom
3. **Meet the Queens**: View promo materials
4. **Episode Flow**:
   - Select a challenge type
   - (Optional) Use Producer's Room to override placements
   - Watch performances
   - See results
   - Choose who wins the lip sync
   - Say goodbye to eliminated queen
5. **Finale**: When 4 queens remain, crown your winner!

## 🚀 Getting Started

Simply open `index.html` in your web browser - no build process needed!

```bash

git clone <repo-url>

# Navigate to directory
cd POKE-SIM

open index.html
# or
```
